# Personas

1. **Reporting entity owner** — conveyancer/accountant; wants “just verify this client” and a file for the auditor.
2. **Compliance / office manager** — needs shared firm view, exports, consistent process.
3. **Staff** — starts checks, chases clients; must not need AML jargon.
4. **Client under verification** — completes ID on phone; pays if asked; never sees admin UI.
